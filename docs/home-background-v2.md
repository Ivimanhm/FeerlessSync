# Fondo alternativo de la portada

Archivo: `src/frontend/public/home/background-v2.jpg`.

Generado con la herramienta integrada `image_gen`, usando `src/frontend/public/landscape.jpg` como referencia de estilo. El resultado se convirtió a JPEG con calidad 90, conservando sus dimensiones y composición.

Esta variante se conserva para comparar en `/?fondo=valle`. El paisaje original está en `/?fondo=anterior`. La portada, Campeones e Historial muestran por defecto la variante con dos elementos laterales descrita en [Fondo v3](home-background-v3.md).
